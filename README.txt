ACTIVEPATH - INSTALAÇÃO ANDROID

1. Publicar todo o conteúdo da pasta app_final num endereço HTTPS.
2. Abrir o endereço no Google Chrome do Android.
3. Menu do Chrome > Instalar aplicação ou Adicionar ao ecrã principal.
4. Confirmar o nome ActivePath.

O ícone inclui o símbolo e o nome ActivePath, sem slogan, com versões normal e maskable. Os dados ficam guardados no navegador; usar Perfil > Cópia JSON semanalmente.
